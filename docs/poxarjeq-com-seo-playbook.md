# SEO-плейбук poxarjeq.com (состояние на 2026-11-12)

Свод всего, что выяснено по SEO: данные GSC, технический аудит, рисерч конкурентов, принятые решения и почему.
Источники: выгрузки GSC (3 месяца, 28 дней, отчёт «Google выбрал другой canonical»), Semrush по rate.am (июль 2025),
afm.am, dram.am, banks.am (декабрь 2025), живая проверка сайта curl-ом, разбор кода. Раньше: `docs/seo-audit.md`,
`docs/audit-links-seo-2026-09-27.md`, `docs/404-fix-2026-10-12.md`, `docs/competitive-research-2026-09-27.md`.
Оценки Semrush по конкурентам — оценки, а не реальные клики; наши цифры из GSC точные.

## 1. Ключевые факты
- Всего ~20,8 тыс. кликов за 3 месяца (4,5 тыс. за 28 дней). Концентрация: `/voski/` ≈ 8,5 тыс. (41%, при этом −65% к прошлому периоду),
  `/avto-hamarner.php` 3,3 тыс., `/ru/rubli-dram.php` 2,3 тыс., `/` 1,3 тыс., `/lari-dram.php` 1,0 тыс.
- CTR упал с ~1,6% до ~0,6% после 18.09.2026, дальше «хорошие» и «плохие» дни чередуются. По времени близко к сентябрьскому
  апдейту Google; связь не доказана.
- `փոխարժեք` — наш бренд **и** обычное слово «курс». В GSC по армянскому написанию позиция ≈ 8,5 (5,8 тыс. показов, 15 кликов, CTR 0,26%).
  Латиницей (`taradrami poxarjeq` — 44,7 тыс. показов, поз. 4,4, 403 клика; `drami poxarjeq` — 27,9 тыс., поз. 4,3, 161 клик) мы выше, но это общие
  запросы «курс обмена», а не брендовые. Владелец наблюдает, что Google подменяет армянское написание транслитом — учитывать при разборе GSC.
- Узкие запросы работают: `լարիի փոխարժեքը այսօր` — поз. 2,9, CTR 26%.
- Страницы предложений (кредиты, ипотека, карты) дают ~450 кликов за 3 месяца (`/consumer-loans/acba-bank-71` — 105 + 16 на RU); вклады (`/deposits/…`) — 0 и 3 клика.
- `/charts/` почти без трафика: `/ru/charts/` 19 кликов, AM 0 (за 3 месяца).
- Армянская страница лари упала на 93% при нормальной русской — причина не установлена.

## 3. Конкуренты: что делают и чему учат
| Сайт | Оценка трафика | Чем живёт |
|---|---|---|

Кластеры запросов rate.am (оценка трафика): «в банках (Армении)» ~8,8 тыс.; «сегодня» ~7,5 тыс.; конкретный банк (АКБА, Ардшин, ВТБ…) ~5,4 тыс.;
«на завтра» ~2,5 тыс. (48 запросов); «обменник» ~2,2 тыс.; «в Ереване» ~0,6 тыс.; суммы ~0,5 тыс. (у afm.am ~1,2 тыс.).
Наши показы/клики по тем же кластерам (3 мес.): «сегодня» 221 тыс. / 4 422; «в банках» 57 тыс. / 898; «в Ереване» 34 тыс. / 749; суммы 95 тыс. / 3 267; «на завтра» 4,9 тыс. / 55.

**Главный вывод:** охват у нас есть, не хватает позиции. По головным запросам мы на местах 8–10, rate.am — на 1–3 (`курс рубля к драму`: у нас 104 тыс. показов,
поз. 8,9, 151 клик). Одним текстом это не лечится: скорость (TTFB), перелинковка, кликабельные тайтлы, накопление ссылок и бренда.

## 4. Что внесено в страницы под запросы конкурентов
- Заголовки таблиц на страницах валют: «Курс … в банках Армении сегодня», «Курс … в обменных пунктах Еревана» (AM-аналоги).
- Блок «Курс … на завтра»: честный ответ без прогноза + текущий лучший курс и изменение за 7 дней из реальных данных.
- Страницы сумм на чистых URL (по образцу afm.am), но с белым списком (46 сумм × 2 языка = 92 URL), уникальным тайтлом/H1/ответом/таблицей по банкам.
  Ограничение белым списком — защита от «scaled content abuse»; **не** расширять до тысяч страниц.
- Страница «Методология» (E-E-A-T для YMYL).

## 5. Принципы для любой новой страницы (чек-лист)
1. Одна страница — один запрос/интент; H1 и тайтл содержат основной запрос (`сегодня`/`այսօր`, пара валют); ответ в первом абзаце (для AI Overviews).
2. Дата и время обновления на видном месте + `dateModified` в разметке; данные из API, не ручные.
3. Контент в HTML (не только JS). Таблицы и ответ — серверный рендер.
4. canonical на себя без query; hreflang AM↔RU парой; страница есть в sitemap с честным lastmod. Нет RU-версии — не ставить `hreflang="ru"`.
5. Уникальный текст на каждый URL; программные страницы только по белому списку и только если у них есть самостоятельный запрос.
6. Хлебные крошки + BreadcrumbList/WebPage разметка; ссылки на смежные страницы; ссылка на «Методологию».
7. Скорость: не добавлять тяжёлые скрипты/шрифты; изображения с `width/height`, `loading="lazy"`.
8. Тексты/ссылки блока — в «Тексты сайта» (см. HANDOFF, раздел 5).
9. Не менять тайтлы и URL пакетом; одна страница → 2–3 недели наблюдения в GSC.

## 6. Что мониторить в GSC (после деплоя и дальше раз в неделю)
- «Покрытие»: падение числа «Страница с редиректом» / «Дубликат: Google выбрал другой canonical»; рост «Не найдено (404)» после включения честных 404 — это нормально.
- «Файлы Sitemap»: `sitemap.xml` отправлен, оба вложенных файла прочитаны, число обнаруженных URL ≈ 200 + новости.
- «Эффективность»: `курс рубля к драму`, `rubli dram`, `курс доллара к драму` — позиция и CTR; страницы сумм (`/dollar-dram/…`) — показы по запросам «1000 долларов в драмах».
- Core Web Vitals / TTFB (после увеличения воркеров).
- Armenian-script запросы (`փոխարժեք`, `դրամի փոխարժեքը այսօր`) отдельно от транслита.

## 7. Что НЕ делать
- Не генерировать тысячи страниц сумм/банков; не копировать чужие страницы 1:1.
- Не прятать/подменять контент для Google, не наращивать ссылки сетью своих сайтов.
- Не менять URL-структуру без редиректов и согласования; не удалять страницы, приносящие клики (`/voski/`, `/avto-hamarner.php`, страницы предложений кредитов).
- Не писать прогнозов курса как фактов.

## 10. poxarjeq.am (отдельный репозиторий `unixanet/poxarjeq.am`)
Это второй сайт владельца на другом коде (PHP, три языка через `?lang=`, данные из API poxarjeq.com, своя админка). Конкретные находки и план —
в том репозитории: `docs/NEXT-STEPS.md`. Общие принципы:
1. Два сайта не должны дублировать друг друга: один и тот же контент на двух доменах — каннибализация. У .am — своя роль (язык/ниша/формат), у .com — своя.
2. Перелинковка между сайтами — только по делу (пользователю полезно), не «для передачи веса».
3. Если домен .am имеет историю/ссылки — смотреть в GSC и Semrush до любых переносов; 301 и объединения — только после данных.
4. Общие компоненты можно переиспользовать: API v2 (`docs/api-v2.md`), Telegram-бот (`telegram/README.md`), система редактируемых текстов, чек-лист из раздела 5.
