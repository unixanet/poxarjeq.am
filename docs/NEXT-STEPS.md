# poxarjeq.am — находки по коду и план (на 2026-11-12)

Сделано при подключении репозитория из сессии poxarjeq.com. **Код сайта не менялся**, добавлены только документы в `docs/` и ссылка в `CLAUDE.md`.
Контекст про большой сайт — `docs/poxarjeq-com-handoff.md`, SEO-выводы и данные конкурентов — `docs/poxarjeq-com-seo-playbook.md`.
Правила .am (`CLAUDE.md`): только `main`, без CSS-файлов, тексты через админку, без правок URL/canonical/hreflang/robots/sitemap/тайтлов без одобрения владельца.
Поэтому всё, что ниже в разделе «SEO», — предложения, ждут «да».

## Что за сайт (по коду)
PHP, три языка hy/ru/en (переключение `?lang=`), курсы из API poxarjeq.com (`API_BASE`, кэш 15 мин), своя MySQL (`config.db.php`) и админка `/admin/`,
страницы банков `/ameriabank`, филиалов `/ameriabank/vanadzor` (через `.htaccess`, значит Apache/LiteSpeed — проверить, что хостинг понимает rewrite),
валюты `currency.php?cur=USD`, тексты в `includes/content_defaults.php`, Tailwind через Play CDN (`includes/tw.php`).

## Находки (проверено чтением кода)
| # | Что | Почему важно | Приоритет |
|---|---|---|---|
| 1 | Языки через `?lang=`: `includes/header.php` вырезает `lang` из canonical, но hreflang `ru`/`en` указывают на `…?lang=ru`/`…?lang=en` | Google получает конфликт: страницы ru/en канонизируются на hy-URL и сами проиндексироваться не могут; hreflang-пары недействительны | высокий |
| 2 | `robots.txt`: `Sitemap: https://example.com/sitemap.php` (заглушка) | поисковик не найдёт sitemap | высокий (одна строка) |
| 3 | `sitemap.php`: адреса валют `currency.php?cur=…`, нет ru/en, `lastmod` всегда «сегодня», нет hreflang | слабый сигнал; lastmod обесценивается | средний |
| 4 | Tailwind Play CDN (`cdn.tailwindcss.com`) на публичных страницах | задержка и JS-рендер стилей, плохо для LCP/CLS; у .com — локальная сборка | высокий для скорости |
| 5 | Нет честного 404 для неизвестных путей (rewrite `^([a-z0-9-]+)/?$ → bank.php`) — проверить, что неизвестный код банка даёт 404, а не пустую страницу | soft-404 | проверить |
| 6 | Нет страницы «Методология» и сигналов доверия | YMYL | средний |
| 7 | Домен `poxarjeq.am` из моей песочницы не открывается (нет ответа) — возможно, ещё не направлен на хостинг | проверить DNS/хостинг | — |

## Предлагаемый порядок (после одобрения)
1. Исправить `robots.txt` (адрес sitemap) — тривиально, без риска.
2. Языки: перейти на путь вместо `?lang=` (`/`, `/ru/`, `/en/`) с 301 со старых адресов и корректными canonical/hreflang — **самое важное для SEO этого сайта**
   (по образцу .com: `/ru/…`). Решение за владельцем; нужен план редиректов.
3. Sitemap: индекс по языкам и типам (валюты, банки, филиалы), честный `lastmod`, hreflang.
4. Скорость: заменить Play CDN на сборку Tailwind (нужен способ сборки на хостинге; на .com это cron раз в минуту) или отдавать готовый CSS (в .am правило «никаких CSS-файлов»
   нужно будет пересмотреть с владельцем: готовый собранный файл ≠ ручной CSS).
5. Определить роль сайта относительно .com (не дублировать контент; см. раздел 10 SEO-плейбука) и под эту роль подобрать запросы (армянский/английский, банки, филиалы).
6. Переиспользовать с .com: Telegram-бот курсов (`telegram/` в poxarjeqv2, другой `api_url`/`chat_id`), страницы сумм, блок методологии, чек-лист новых страниц.
