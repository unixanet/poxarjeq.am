# SEO-отчёт poxarjeq.am (2026-11-16)

Основа: выгрузка Google Search Console за 3 месяца (запросы и страницы отдельными листами, связка «запрос → страница» в выгрузке отсутствует, поэтому соответствие построено по смыслу запроса) и официальные правила Google Search Central.

## Что проверено у Google (прочитано напрямую)

- **Title и description:** жёсткого лимита длины нет, обрезается по ширине экрана; на каждой странице нужен свой, не отличающийся одним словом; для страниц из базы данных Google прямо поощряет генерацию описаний из данных страницы. У нас title и description берут живые числа (лучший курс, банк, место, часы работы).
- **Полезный контент:** калькуляторы и инструменты считаются основным содержимым; требуются оригинальная информация и добавленная ценность. Поэтому на каждой валюте и банке есть собственный текст и данные (вилка между банками, разница в драмах, спред, место банка), а не только таблица.
- **Doorway и масштабируемый контент:** массовые похожие страницы без своей ценности — нарушение. Поэтому страницы «банк + валюта» и «город» содержат уникальные расчёты, график и сравнение, доступны по обычной иерархии ссылок (банк → валюта, валюта → банк, город → отделение), а не только из карты сайта.
- **FAQ-разметка:** FAQ-расширенные результаты отключены Google с 7 мая 2026. Вопросы и ответы оставлены как видимый текст для людей и под длинные запросы; на разметку ради сниппетов не рассчитываем.
- **hreflang:** обязательна взаимность и полные адреса; сделано (hy, ru, en, x-default на армянский), язык определяется адресом.
- **Ссылки:** только `<a href>`, описательный текст, каждая ссылка с `title`; изображения с `alt`, `width`, `height` (проверка того же правила, что в админке, по всем типам страниц и трём языкам: замечаний по ссылкам, картинкам и H1 нет; у нескольких длинных названий отделений title до 78 знаков).
- **Сравнение с Wise, XE, rate.am, afm.am:** эти сайты из окружения недоступны (сетевой доступ закрыт), я их не открывал. Выводы про структуру взяты из правил Google и практики, а не из просмотра конкурентов. Если откроете доступ к этим доменам, перепроверю.

## Технические проверки (все пройдены локально)
- Один H1 на каждой странице; у каждой ссылки есть `title`; у каждой картинки `alt`, `width`, `height`.
- Для страниц с 404: `noindex`, без hreflang.
- Канонические адреса и hreflang: у каждой языковой версии свой, взаимные.
- `sitemap.xml`: индекс из 4 файлов, 3 языка с hreflang у каждого адреса, `lastmod` из данных.

## Что остаётся
- Скорость: Tailwind подключён через Play CDN (правило проекта «без CSS-файлов»). Google не рекомендует Play CDN для продакшна, это главный технический минус; решение за владельцем (собранный файл вместо CDN).
- В описаниях банков на странице используются только проверяемые факты (юрлицо, SWIFT, принадлежность группе, список валют). Прежние общие фразы («инновационный», «с долгой историей») убраны с публичных страниц.
- Адреса отделений в данных часто без улицы («ք. Երևան»): страница честно пишет «ճշգրիտ փողոցը ճշտեք հեռախոսով» вместо выдуманного адреса. Улицы нужно внести в админке (Филиалы).
