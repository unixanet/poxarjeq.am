  кредиты, ипотека, вклады, карты, золото, крипто, рейтинг банков и страхования, новости, калькуляторы. Языки: армянский
  (корень `/`) и русский (`/ru/`). Трафик ~15 тыс./мес., 99% — Google и Яндекс, поэтому SEO критично.
  Название «Փոխարժեք / Poxarjeq» — это и бренд, и обычное слово «курс обмена» (для поиска это важно, см. SEO-плейбук).
- **poxarjeq.am** — отдельный репозиторий `unixanet/poxarjeq.am` (в README назван BestRate.am), сайт-«дочка» poxarjeq.com, который владелец
  развивает как второй сайт (куплен/подключён в ноябре 2026). Свой `CLAUDE.md` с правилами. Факты по коду (на 2026-11-12):
  три языка hy/ru/en, переключение через `?lang=`; курсы берутся из API poxarjeq.com (`https://poxarjeq.com/api`, кэш 15 мин); своя MySQL и админка `/admin/`
  (тексты, банки, филиалы, меню, валюты, SEO и llms.txt); Tailwind подключён через Play CDN (`includes/tw.php`) — в отличие от .com, где локальная сборка;
  цвет бренда там синий `#2563eb`/`#0078D4` (у .com — `#2194c0`). Контекст и план для него — в том репозитории: `docs/poxarjeq-com-handoff.md`,

## 3. Сервер
FastPanel, путь `/var/www/poxarjeq_com_usr/data/www/poxarjeq.com`, nginx + PHP-FPM 8.4 (**2 воркера — главный риск по
скорости**, холодный запрос до 7 с), MySQL с отдельными базами под модули (`financerates` — курсы, `news`, `rating` — банки,
`insurance`, `cards`, `hipotek`, `sparoghakanhy`, `usanoghakan`, `gold`, `avandner`, `madowl` — админка/тексты/редиректы).
`.htaccess` на nginx не работает; nginx-конфиг в репозиторий не входит (правится в FastPanel → Nginx). Несуществующие
пути без расширения nginx отправляет в корневой `index.php` (catch-all) — на этом построены 404 и страницы сумм (см. 6).

## 5. Система «Тексты сайта» (обязательна для новых блоков)
Таблица `madowl.site_texts` (ключ + язык → значение), миграция `sql/madowl_site_texts.sql`. Пустое значение = умолчание из кода,
при сбое БД сайт работает как раньше. Новый блок = (1) файл умолчаний `includes/<имя>-defaults.php` (`['am'=>[…],'ru'=>[…]]`),
(2) строка группы в `includes/site-texts-registry.php` (title, langs, preview, defaults, labels), (3) в шаблоне тексты берутся через
`pxq_texts_apply('<группа>', $lang, $defaults)` / `pxq_text()`, а не пишутся в разметке. Ключи: `*_href`/`*_url` — ссылки
(проверяются), `*_html` — безопасный HTML (`pxq_html_clean`), `show`/`pos` — показ и порядок, ключи с `_` в начале — технические.
Группы: home, footer, homenews, banks, insurance, rating, currency, crypto, gold, catalog, menu, index, pages, news, api, tg,
notfound, amount, method. Подробности — `includes/site-texts.php` и `docs/madowl-admin-plan.md`.
Тайтлы/description страниц живут **в БД `madowl.pages`** (админка), в `includes/config.php` и `ru/config.php` — только запасные.

## 9. Как тестировать без сервера (то, что делалось в сессиях)
1. Скопировать репозиторий во временную папку (без `.git`, `sql`, `docs`), запустить `php -S 127.0.0.1:PORT -t . router.php`, где router отдаёт статику,
   прямые `.php` и роутит остальное в `index.php`/`ru/index.php` (имитация nginx catch-all).
2. БД локально нет: страницы с запросами к MySQL падают. Для визуальной проверки подставлять фейковые данные (в копии, не в репозитории), например
   заменить `pxq_cur_data()` в копии `currency-page.php`.
3. Tailwind: установить `tailwindcss@3.4.17` в `/tmp`, `content` = php-файлы копии, собрать в `css/output.css` копии.
4. Скриншоты: Playwright (chromium уже установлен, `require('playwright')`), viewport 390 (мобильный) и 1280 (десктоп).
5. Перед пушем: `php -l` по изменённым файлам, `node --check` для инлайновых скриптов, `php tests/*.php`.

## 10. Грабли (уже наступали)
- Заливка по FTP частями: если не залить новые файлы из `includes/`, страницы падают в пустой экран. В отчёте всегда перечислять файлы.
- `ru/header.php` начинается с `<!DOCTYPE>` — редиректы/guard вызывать до вывода; `require 'config.php'` в `ru/*` резолвится относительно файла.
- `header.php`, подключённый внутри функции, видит только её локальные переменные — глобальные объявлять через `global`.
- Относительные ссылки на главной порождали мусорные URL (`/ru//calculators/...`) — только абсолютные от корня.
- Картинки, присланные в чат, на диск не сохраняются — иконки/логотипы владельцу надо просить загрузить в репозиторий или рисовать аналог.
- Файлы владельца из чата лежат в `/root/.claude/uploads/<session>/` (выгрузки Semrush — UTF-16, табуляция).
- Не менять тайтлы/структуру URL «пакетом»: сначала одна страница, затем 2–3 недели наблюдения в GSC.
